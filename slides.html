AI month-end close for accounting firms. Every client's books are reconciled by an agent in its own sealed sandbox on Vultr.
The problem
The monthly grind

Firms close the books for dozens of clients every month. Bank reconciliation eats the days: hundreds of lines matched by hand, leftovers chased, entries booked, workpapers written.

AI has to run code

Doing it for real means an agent writing and executing code on confidential client data. The data is untrusted too: anyone who pays a client writes text into its bank statement.

Firms say no

No firm lets a model loose on client books unless every action is contained, every entry is reviewed by a person, and every number can be proven.

Our solution

One click closes the month. Each client gets its own sealed sandbox.

1

Close September starts one agent run per client, all 12 in parallel.

2

GLM 5.3 on Vultr Serverless Inference works out each bank's export format and writes Python that runs only inside that client's gVisor sandbox: no network, read-only inputs, no access to the ledger.

3

The control plane checks every number (schema, arithmetic, ties to 0.00) and stores the SHA-256 of every output.

4

A reviewer approves each adjusting entry before it exports to QuickBooks, Xero or NetSuite. Replay re-runs the recorded code in a fresh sandbox and proves the outputs by hash.

Live app: 12 clients closed in about 30 seconds, 68 of 68 planted discrepancies found, every difference 0.00. Judges can also upload their own bank export.

Built on Vultr

Vultr is the system of control and record, and it works on the live URL today.

Cloud Compute

A control-plane VM (orchestrator, agent loop, API) and two sandbox-host VMs running one gVisor container per client run, with failover.

Serverless Inference

Every LLM call: GLM 5.3 plans and writes the code, GLM 5.3 Flash is the fallback, Nemotron 3.5 Content Safety checks suspicious input text.

Managed PostgreSQL

System of record: clients, runs, hash-chained run events, signed approvals, audit log.

Object Storage

Inputs, outputs, evidence packs and uploads in a private bucket, served by short-lived links.

VPC Network

The sandbox runner listens only on its private address, reachable only from the control plane.

Firewall Groups

Control plane: 80 and 443 only. Sandbox hosts: nothing inbound from the internet.
